- No per-frame storage in DB (tracking data lives in memory during processing only)
- No separate queue service — Postgres jobs table only
- No Spring Boot — FastAPI only
- Worker and API run on same Render service at MVP scale
- CPU inference only for v1 (GPU if processing time becomes unacceptable)
