8. Suggested data model for the MVP

Let’s keep the database understandable.

videos

Stores the uploaded video.

Fields:

id
filename
storage_url
status
duration_seconds
fps
created_at
analysis_jobs

Tracks processing state.

Fields:

id
video_id
status
started_at
completed_at
error_message
players

Represents tracked player identities inside one video.

Fields:

id
video_id
track_label
jersey_number
jersey_color
team_color
is_target_player
player_tracks

Stores location over time.

Fields:

id
player_id
frame_index
timestamp
bbox_x1
bbox_y1
bbox_x2
bbox_y2
Bounding box

A bounding box is the rectangle around a detected object.

ball_tracks

Stores ball positions.

Fields:

id
video_id
frame_index
timestamp
bbox_x1
bbox_y1
bbox_x2
bbox_y2
events

Stores detected basketball events.

Fields:

id
video_id
player_id
event_type
start_time
end_time
confidence
metadata_json

Event types might be:

possession
dribble
pass
shot_attempt
made_shot
rebound
player_stats

Stores final aggregated stats.

Fields:

id
video_id
player_id
points
field_goals_made
field_goals_attempted
three_points_made
three_points_attempted
rebounds
assists
steals
blocks
