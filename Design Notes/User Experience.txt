User flow

User uploads video

User enters:
    jersey number
    jersey color

App says “processing”

Backend runs analysis

User sees:
    target player detected
    action timeline
    estimated stats
    confidence levels
    maybe clips later

This is useful because system design should always support a clear user flow.


*********** USER TRUST, AI CONFIDENCE *********** 

Since AI will sometimes be wrong, include confidence in your results.

Example:

target player match confidence: 0.89
shot detection confidence: 0.78
made basket confidence: 0.83

This helps users trust the product more.

It also lets you say:

“high confidence shot”
“low confidence rebound detection”

That is much better than pretending every output is perfect.
